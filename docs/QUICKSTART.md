# Quick Start

## 5 分钟跑起来

### 1. 克隆

```bash
git clone https://gitee.com/qyfanshen/gc.qyfanshen.git
cd gc.qyfanshen.com
```

### 2. 环境准备

- 任意现代浏览器

### 3. 启动

```bash
python -m http.server 8080
# → http://localhost:8080
```

### 4. 下一步

- 阅读 [`ARCHITECTURE.md`](ARCHITECTURE.md) 了解系统设计
- 阅读 [`DEPLOYMENT.md`](DEPLOYMENT.md) 部署到生产环境
